# source

The input dataset: *Konfigurationsunderlag – Harmoniserad datamängd cancergenomik*, consultation version, from RCC i samverkan (NPO Cancersjukdomar) through NAG CancerGenomik.

- `xlsx/Konfigurationsunderlag genomik.xlsx`: the original Excel file (18 sheets), unchanged. Download URL not recorded (the consultation was published via cancercentrum.se).
- `csv/`: UTF-8 CSV export of every sheet, one file per sheet name; export script not committed.

© RCC i samverkan. Read-only input; analysis is in `../analysis/` and `../valuesets/`.
