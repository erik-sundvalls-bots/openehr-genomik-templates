# ig

FHIR IG source for the EHR Slice, built with SUSHI and (optionally) the HL7 IG Publisher.

- `sushi-config.yaml`, `ig.ini`: IG configuration (FHIR R4, depends on Genomics Reporting IG 3.0.0 and the Swedish base IG `hl7se.fhir.base` 1.1.0). Canonical URL is an `example.org` placeholder.
- `input/fsh/`: profiles, examples and terminology (`terminology.fsh` is generated by `../tools/gen_terminology_fsh.py`); `input/pagecontent/`: IG pages (`roundtrip.md` is written by `../tools/gen_ig_artefacts.py`); `input/resources/`: openEHR and FHIRconnect artefacts as `Binary` + `Library`, generated by `../tools/gen_ig_artefacts.py`.
- `fsh-generated/`: SUSHI output (committed; `../tools/make_bundles.py` reads it).
- `QA-SUMMARY.md`: summary of the last IG Publisher QA run.
- `output/`, `temp/`, `template/`, `input-cache/`: IG Publisher working folders, git-ignored.
