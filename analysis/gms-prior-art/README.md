# Swedish/GMS prior-art archetypes

ADL 1.4 archetypes from earlier Swedish genomics work, kept for comparison only; they are not used by the templates.

- `confirmed_cancer.v2`, `general_sequencing_result_parameter.v0`, `mtbp_classification.v0`, `sequencing_assay.v1`, `sequencing_result.v0`.
- Source: Genomic Medicine Sweden (GMS) information specifications / local archetypes of the Swedish model library (*modellbibliotek*), see `../../docs/decisions.md`. Exact repository URL and commit not recorded.
- Used in `../../docs/decisions.md` (e.g. ASCO/AMP/ESCAT search) as prior art.
