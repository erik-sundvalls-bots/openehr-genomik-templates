# docs/img

Images for the docs and the consultation response.

- `ehr-slice-illustration.svg` / `.png`: overview of an EHR Slice (Swedish labels): openEHR templates, FHIRconnect mappings, FHIR profiles and code systems/value sets packaged in one FHIR IG, between an openEHR CDR and a FHIR API.
- `make_ehr_slice_illustration.py`: generates both files (`python3 make_ehr_slice_illustration.py` from the repo root; needs `cairosvg`).

Source: our own drawing, inspired by the illustration in openEHR International's article ["What is an EHR Slice and why is it relevant to the EHDS?"](https://openehr.org/what-is-an-ehr-slice-and-why-is-it-relevant-to-the-ehds/). No artwork from that image is reused.
