# build

Derived artefacts, regenerated by `../tools/build.sh`. Do not edit by hand.

- `opt14/`, `oet14/`: OPT 1.4 and OET 1.4 of the genomics cancer report and genomics request templates, exported from `../templates/adl2/` with Ehrtslib (`deno task export:opt14` / `export:oet14`), English and Swedish.
- `ehrtslib-adl14/`, `archie-adl14/`: ADL 1.4 down-conversions of `../archetypes/drafts/`, made with Ehrtslib (`../tools/ehrtslib-down14.ts`) and with the ADL2→1.4 converter in our Archie fork. Kept side by side for comparison. Both also hold two benchmark cases (`CLUSTER.organisation.v1.0.4`, `EVALUATION.code_list_parent.v1.0.0`) from `../docs/adl14-benchmark-ehrtslib-vs-archie.md`; `build.sh` does not regenerate those.
- `archie-validation.txt`: Archie parse + flatten + validate of all ADL2 archetypes and templates.
- `xsd-validation.txt`: OPT/OET checks against the openEHR XSDs.
- `ehrtslib-export-log.txt`: Ehrtslib export output.
