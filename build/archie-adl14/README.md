# ADL 1.4 via the Archie fork

ADL 1.4 versions of the draft archetypes (`../../archetypes/drafts/`), produced by the ADL2→1.4 down-converter (`ADL2ToADL14Cli`) in our Archie fork, run from `../../tools/build.sh`. Compare with `../ehrtslib-adl14/`; see `../../docs/adl14-benchmark-ehrtslib-vs-archie.md`.

`CLUSTER.organisation.v1.0.4` (CKM round trip) and `EVALUATION.code_list_parent.v1.0.0` (ADL2 spec 9.9 example) are benchmark cases from `../../docs/adl14-benchmark-ehrtslib-vs-archie.md`; `build.sh` does not regenerate them.
