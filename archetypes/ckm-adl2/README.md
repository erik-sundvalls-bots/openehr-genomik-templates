# CKM archetypes (ADL2)

- The 25 archetypes of `../ckm/`, converted from ADL 1.4 to ADL2 with Archie 3.21 (`../../tools/ArchieConvert.java`); the file name carries the CKM revision.
- 10 CLUSTER archetypes also have a local Swedish (`sv`) translation, added by `../../tools/add_sv_translation.py` from `../../translations/sv/`. It is marked as a local draft translation, not CKM-reviewed.
- Used as the archetype library for the ADL2 templates, Archie validation and the OPT/OET 1.4 export (`../../tools/build.sh`).
