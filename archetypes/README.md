# archetypes

- `ckm/`: unchanged ADL 1.4 copies of the international CKM archetypes used by the templates.
- `ckm-adl2/`: the same archetypes converted to ADL2, some with a local Swedish translation added.
- `drafts/`: our own ADL2 specialisations and new archetypes.
- `CKM-CATALOG.md`: archetype IDs, CKM CIDs, lifecycle status, revisions and URLs.

All three folders are read by `../tools/build.sh` (Archie validation, OPT/OET export).
